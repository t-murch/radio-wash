# Radiowash logo assets

- radiowash-logo-light.png/.svg — primary wordmark, light backgrounds (ink #221E17, strike #0F5F5C)
- radiowash-logo-dark.png/.svg — for dark backgrounds (#F2EDE2, strike #5FB3AB)
- radiowash-mark.png/.svg — struck "Rw" app icon / favicon mark

PNGs are 4x captures (transparent background on the wordmarks).
SVGs use live text with a Google-hosted Newsreader import — they render correctly in browsers; for print/design tools, convert text to outlines or use the PNGs.

Rules: strike sits at 54% cap height, thickness ≈ 11% of font size, rounded ends. Below 14px drop the strike and set "wash" in teal.
